# CMAKE_ANDROID_ARM_NEON

Added in version 3.7.

When [Cross Compiling for Android](https://cmake.org/cmake/help/v4.4/manual/cmake-toolchains.7.html#cross-compiling-for-android) and [`CMAKE_ANDROID_ARCH_ABI`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_ANDROID_ARCH_ABI.html#variable:CMAKE_ANDROID_ARCH_ABI) is set to `armeabi-v7a` set `CMAKE_ANDROID_ARM_NEON` to `ON` to target ARM NEON devices.
