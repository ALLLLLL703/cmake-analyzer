# CMAKE_FRAMEWORK

Added in version 3.15.

Default value for [`FRAMEWORK`](https://cmake.org/cmake/help/v4.4/prop_tgt/FRAMEWORK.html#prop_tgt:FRAMEWORK) of targets.

This variable is used to initialize the [`FRAMEWORK`](https://cmake.org/cmake/help/v4.4/prop_tgt/FRAMEWORK.html#prop_tgt:FRAMEWORK) property on all the targets. See that target property for additional information.
