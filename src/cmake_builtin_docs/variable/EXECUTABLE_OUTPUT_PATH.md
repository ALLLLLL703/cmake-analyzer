# EXECUTABLE_OUTPUT_PATH

Old executable location variable.

The target property [`RUNTIME_OUTPUT_DIRECTORY`](https://cmake.org/cmake/help/v4.4/prop_tgt/RUNTIME_OUTPUT_DIRECTORY.html#prop_tgt:RUNTIME_OUTPUT_DIRECTORY) supersedes this variable for a target if it is set. Executable targets are otherwise placed in this directory.
