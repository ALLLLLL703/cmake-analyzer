# CMAKE_RUNTIME_OUTPUT_DIRECTORY

Where to put all the [RUNTIME](https://cmake.org/cmake/help/v4.4/manual/cmake-buildsystem.7.html#runtime-output-artifacts) target files when built.

This variable is used to initialize the [`RUNTIME_OUTPUT_DIRECTORY`](https://cmake.org/cmake/help/v4.4/prop_tgt/RUNTIME_OUTPUT_DIRECTORY.html#prop_tgt:RUNTIME_OUTPUT_DIRECTORY) property on all the targets. See that target property for additional information.
