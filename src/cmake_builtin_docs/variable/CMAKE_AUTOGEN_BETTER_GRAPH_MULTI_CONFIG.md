# CMAKE_AUTOGEN_BETTER_GRAPH_MULTI_CONFIG

Added in version 3.29.

This variable is used to initialize the [`AUTOGEN_BETTER_GRAPH_MULTI_CONFIG`](https://cmake.org/cmake/help/v4.4/prop_tgt/AUTOGEN_BETTER_GRAPH_MULTI_CONFIG.html#prop_tgt:AUTOGEN_BETTER_GRAPH_MULTI_CONFIG) property on all targets as they are created. See that target property for additional information.
