# CMAKE_LINK_DIRECTORIES_BEFORE

Added in version 3.13.

Whether to append or prepend directories by default in [`link_directories()`](https://cmake.org/cmake/help/v4.4/command/link_directories.html#command:link_directories).

This variable affects the default behavior of the [`link_directories()`](https://cmake.org/cmake/help/v4.4/command/link_directories.html#command:link_directories) command. Setting this variable to `ON` is equivalent to using the `BEFORE` option in all uses of that command.
