# CMAKE_AUTOMOC_PATH_PREFIX

Added in version 3.16.

Whether to generate the `-p` path prefix option for `moc` on [`AUTOMOC`](https://cmake.org/cmake/help/v4.4/prop_tgt/AUTOMOC.html#prop_tgt:AUTOMOC) enabled Qt targets.

This variable is used to initialize the [`AUTOMOC_PATH_PREFIX`](https://cmake.org/cmake/help/v4.4/prop_tgt/AUTOMOC_PATH_PREFIX.html#prop_tgt:AUTOMOC_PATH_PREFIX) property on all the targets. See that target property for additional information.

The default value is `OFF`.
