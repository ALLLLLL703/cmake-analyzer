# CMAKE_APPBUNDLE_PATH

[Semicolon-separated list](https://cmake.org/cmake/help/v4.4/manual/cmake-language.7.html#cmake-language-lists) of directories specifying a search path for macOS application bundles used by the [`find_program()`](https://cmake.org/cmake/help/v4.4/command/find_program.html#command:find_program), and [`find_package()`](https://cmake.org/cmake/help/v4.4/command/find_package.html#command:find_package) commands.

There is also an environment variable [`CMAKE_APPBUNDLE_PATH`](https://cmake.org/cmake/help/v4.4/envvar/CMAKE_APPBUNDLE_PATH.html#envvar:CMAKE_APPBUNDLE_PATH), which is used as an additional list of search directories.
