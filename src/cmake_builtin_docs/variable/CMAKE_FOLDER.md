# CMAKE_FOLDER

Added in version 3.12.

Set the folder name. Use to organize targets in an IDE.

This variable is used to initialize the [`FOLDER`](https://cmake.org/cmake/help/v4.4/prop_tgt/FOLDER.html#prop_tgt:FOLDER) property on all the targets. See that target property for additional information.
