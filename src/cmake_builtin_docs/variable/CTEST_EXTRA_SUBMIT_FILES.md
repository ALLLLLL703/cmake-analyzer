# CTEST_EXTRA_SUBMIT_FILES

Specify files for [`ctest_submit(PARTS ExtraFiles)`](https://cmake.org/cmake/help/v4.4/command/ctest_submit.html#command:ctest_submit) to submit in a [`ctest(1)`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#manual:ctest(1)) [Dashboard Client](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#dashboard-client) script, or on the **ctest** command line via the [`-D`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#cmdoption-ctest-dashboard-D) option.
