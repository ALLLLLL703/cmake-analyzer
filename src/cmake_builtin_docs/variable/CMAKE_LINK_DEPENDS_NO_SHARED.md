# CMAKE_LINK_DEPENDS_NO_SHARED

Whether to skip link dependencies on shared library files.

This variable initializes the [`LINK_DEPENDS_NO_SHARED`](https://cmake.org/cmake/help/v4.4/prop_tgt/LINK_DEPENDS_NO_SHARED.html#prop_tgt:LINK_DEPENDS_NO_SHARED) property on targets when they are created. See that target property for additional information.
