# PROJECT_COMPAT_VERSION

Added in version 4.3.

Value given to the `COMPAT_VERSION` option of the most recent call to the [`project()`](https://cmake.org/cmake/help/v4.4/command/project.html#command:project) command, if any. To obtain the compatibility version of the top level project, see the [`CMAKE_PROJECT_COMPAT_VERSION`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_PROJECT_COMPAT_VERSION.html#variable:CMAKE_PROJECT_COMPAT_VERSION) variable.
