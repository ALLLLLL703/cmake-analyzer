# CMAKE_EXECUTABLE_SUFFIX

The suffix for executables on the target platform.

The suffix to use for the end of an executable filename if any, `.exe` on Windows.

[`CMAKE_EXECUTABLE_SUFFIX_<LANG>`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_EXECUTABLE_SUFFIX_LANG.html#variable:CMAKE_EXECUTABLE_SUFFIX_%3CLANG%3E) overrides this for language `<LANG>`.

See the [`CMAKE_HOST_EXECUTABLE_SUFFIX`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_HOST_EXECUTABLE_SUFFIX.html#variable:CMAKE_HOST_EXECUTABLE_SUFFIX) variable for the executable suffix on the host platform.
