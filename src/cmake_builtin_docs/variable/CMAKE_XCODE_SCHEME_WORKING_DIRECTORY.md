# CMAKE_XCODE_SCHEME_WORKING_DIRECTORY

Added in version 3.17.

Specify the `Working Directory` of the *Run* and *Profile* actions in the generated Xcode scheme.

This variable initializes the [`XCODE_SCHEME_WORKING_DIRECTORY`](https://cmake.org/cmake/help/v4.4/prop_tgt/XCODE_SCHEME_WORKING_DIRECTORY.html#prop_tgt:XCODE_SCHEME_WORKING_DIRECTORY) property on all targets.

Please refer to the [`XCODE_GENERATE_SCHEME`](https://cmake.org/cmake/help/v4.4/prop_tgt/XCODE_GENERATE_SCHEME.html#prop_tgt:XCODE_GENERATE_SCHEME) target property documentation to see all Xcode schema related properties.
