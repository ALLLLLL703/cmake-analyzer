# CMAKE_INSTALL_NAME_DIR

Directory name for installed targets on Apple platforms.

`CMAKE_INSTALL_NAME_DIR` is used to initialize the [`INSTALL_NAME_DIR`](https://cmake.org/cmake/help/v4.4/prop_tgt/INSTALL_NAME_DIR.html#prop_tgt:INSTALL_NAME_DIR) property on all targets. See that target property for more information.
