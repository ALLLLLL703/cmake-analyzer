# CMAKE_\<LANG\>_ARCHIVER_WRAPPER_FLAG_SEP

Added in version 4.0.

This variable is used with [`CMAKE_<LANG>_ARCHIVER_WRAPPER_FLAG`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_LANG_ARCHIVER_WRAPPER_FLAG.html#variable:CMAKE_%3CLANG%3E_ARCHIVER_WRAPPER_FLAG) variable to format `ARCHIVER:` prefix in the static library options (see [`STATIC_LIBRARY_OPTIONS`](https://cmake.org/cmake/help/v4.4/prop_tgt/STATIC_LIBRARY_OPTIONS.html#prop_tgt:STATIC_LIBRARY_OPTIONS)).

When specified, arguments of the `ARCHIVER:` prefix will be concatenated using this value as separator.
