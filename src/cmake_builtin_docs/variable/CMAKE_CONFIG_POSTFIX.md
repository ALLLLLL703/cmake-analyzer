# CMAKE_\<CONFIG\>_POSTFIX

Default filename postfix for libraries under configuration `<CONFIG>`.

When a non-executable target is created its [`<CONFIG>_POSTFIX`](https://cmake.org/cmake/help/v4.4/prop_tgt/CONFIG_POSTFIX.html#prop_tgt:%3CCONFIG%3E_POSTFIX) target property is initialized with the value of this variable if it is set.
