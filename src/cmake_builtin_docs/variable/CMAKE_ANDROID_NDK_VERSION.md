# CMAKE_ANDROID_NDK_VERSION

Added in version 3.20.

When [Cross Compiling for Android with the NDK](https://cmake.org/cmake/help/v4.4/manual/cmake-toolchains.7.html#cross-compiling-for-android-with-the-ndk) and using an Android NDK version 11 or higher, this variable is provided by CMake to report the NDK version number.
