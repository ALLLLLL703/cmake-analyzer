# CMAKE_\<LANG\>_CPPLINT

Added in version 3.8.

Default value for [`<LANG>_CPPLINT`](https://cmake.org/cmake/help/v4.4/prop_tgt/LANG_CPPLINT.html#prop_tgt:%3CLANG%3E_CPPLINT) target property. This variable is used to initialize the property on each target as it is created. This is done only when `<LANG>` is `C` or `CXX`.
