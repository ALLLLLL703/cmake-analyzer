# CMAKE_AUTOMOC_EXECUTABLE

Added in version 3.27.

This variable is used to initialize the [`AUTOMOC_EXECUTABLE`](https://cmake.org/cmake/help/v4.4/prop_tgt/AUTOMOC_EXECUTABLE.html#prop_tgt:AUTOMOC_EXECUTABLE) property on all the targets. See that target property for additional information.

By default it is empty.
