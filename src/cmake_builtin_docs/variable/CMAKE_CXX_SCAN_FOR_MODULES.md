# CMAKE_CXX_SCAN_FOR_MODULES

Added in version 3.28.

Whether to scan C++ source files for module dependencies.

This variable is used to initialize the [`CXX_SCAN_FOR_MODULES`](https://cmake.org/cmake/help/v4.4/prop_tgt/CXX_SCAN_FOR_MODULES.html#prop_tgt:CXX_SCAN_FOR_MODULES) property on all the targets. See that target property for additional information.
