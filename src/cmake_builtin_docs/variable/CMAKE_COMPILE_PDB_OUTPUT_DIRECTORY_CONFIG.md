# CMAKE_COMPILE_PDB_OUTPUT_DIRECTORY_\<CONFIG\>

Added in version 3.1.

Per-configuration output directory for MS debug symbol `.pdb` files generated by the compiler while building source files.

This is a per-configuration version of [`CMAKE_COMPILE_PDB_OUTPUT_DIRECTORY`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_COMPILE_PDB_OUTPUT_DIRECTORY.html#variable:CMAKE_COMPILE_PDB_OUTPUT_DIRECTORY). This variable is used to initialize the [`COMPILE_PDB_OUTPUT_DIRECTORY_<CONFIG>`](https://cmake.org/cmake/help/v4.4/prop_tgt/COMPILE_PDB_OUTPUT_DIRECTORY_CONFIG.html#prop_tgt:COMPILE_PDB_OUTPUT_DIRECTORY_%3CCONFIG%3E) property on all the targets.
