# CTEST_CONFIGURATION_TYPE

Added in version 3.1.

Specify the CTest `DefaultCTestConfigurationType` setting in a [`ctest(1)`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#manual:ctest(1)) [Dashboard Client](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#dashboard-client) script.

If the configuration type is set via [`-C <cfg>`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#cmdoption-ctest-C) from the command line then this variable is populated accordingly.
