# CMAKE_AUTOUIC_SEARCH_PATHS

Added in version 3.9.

Search path list used by [`CMAKE_AUTOUIC`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_AUTOUIC.html#variable:CMAKE_AUTOUIC) to find included `.ui` files.

This variable is used to initialize the [`AUTOUIC_SEARCH_PATHS`](https://cmake.org/cmake/help/v4.4/prop_tgt/AUTOUIC_SEARCH_PATHS.html#prop_tgt:AUTOUIC_SEARCH_PATHS) property on all the targets. See that target property for additional information.

By default it is empty.
