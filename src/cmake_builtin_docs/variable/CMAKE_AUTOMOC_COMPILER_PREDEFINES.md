# CMAKE_AUTOMOC_COMPILER_PREDEFINES

Added in version 3.10.

This variable is used to initialize the [`AUTOMOC_COMPILER_PREDEFINES`](https://cmake.org/cmake/help/v4.4/prop_tgt/AUTOMOC_COMPILER_PREDEFINES.html#prop_tgt:AUTOMOC_COMPILER_PREDEFINES) property on all the targets. See that target property for additional information.

By default it is ON.
