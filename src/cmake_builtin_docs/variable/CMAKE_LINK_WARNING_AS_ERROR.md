# CMAKE_LINK_WARNING_AS_ERROR

Added in version 4.0.

Specify whether to treat warnings on link as errors.

This variable is used to initialize the [`LINK_WARNING_AS_ERROR`](https://cmake.org/cmake/help/v4.4/prop_tgt/LINK_WARNING_AS_ERROR.html#prop_tgt:LINK_WARNING_AS_ERROR) property on all the targets.
