# CMAKE_BUILD_RPATH_USE_ORIGIN

Added in version 3.14.

Whether to use relative paths for the build `RPATH`.

This is used to initialize the [`BUILD_RPATH_USE_ORIGIN`](https://cmake.org/cmake/help/v4.4/prop_tgt/BUILD_RPATH_USE_ORIGIN.html#prop_tgt:BUILD_RPATH_USE_ORIGIN) target property for all targets, see that property for more details.
