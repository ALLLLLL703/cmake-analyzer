# CMAKE_INCLUDE_DIRECTORIES_BEFORE

Whether to append or prepend directories by default in [`include_directories()`](https://cmake.org/cmake/help/v4.4/command/include_directories.html#command:include_directories).

This variable affects the default behavior of the [`include_directories()`](https://cmake.org/cmake/help/v4.4/command/include_directories.html#command:include_directories) command. Setting this variable to `ON` is equivalent to using the `BEFORE` option in all uses of that command.
