# CMAKE_CURRENT_FUNCTION

Added in version 3.17.

When executing code inside a [`function()`](https://cmake.org/cmake/help/v4.4/command/function.html#command:function), this variable contains the name of the current function. It can be useful for diagnostic or debug messages.

See also [`CMAKE_CURRENT_FUNCTION_LIST_DIR`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_CURRENT_FUNCTION_LIST_DIR.html#variable:CMAKE_CURRENT_FUNCTION_LIST_DIR), [`CMAKE_CURRENT_FUNCTION_LIST_FILE`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_CURRENT_FUNCTION_LIST_FILE.html#variable:CMAKE_CURRENT_FUNCTION_LIST_FILE) and [`CMAKE_CURRENT_FUNCTION_LIST_LINE`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_CURRENT_FUNCTION_LIST_LINE.html#variable:CMAKE_CURRENT_FUNCTION_LIST_LINE).
