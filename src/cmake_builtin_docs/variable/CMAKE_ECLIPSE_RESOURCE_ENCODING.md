# CMAKE_ECLIPSE_RESOURCE_ENCODING

Added in version 3.16.

This cache variable tells the [`Eclipse CDT4`](https://cmake.org/cmake/help/v4.4/generator/Eclipse%20CDT4.html#generator:Eclipse%20CDT4) project generator to set the resource encoding to the given value in generated project files. If no value is given, no encoding will be set.
