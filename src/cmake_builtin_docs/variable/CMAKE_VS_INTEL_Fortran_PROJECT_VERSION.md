# CMAKE_VS_INTEL_Fortran_PROJECT_VERSION

When generating for [`Visual Studio 14 2015`](https://cmake.org/cmake/help/v4.4/generator/Visual%20Studio%2014%202015.html#generator:Visual%20Studio%2014%202015) or greater with the Intel Fortran plugin installed, this specifies the `.vfproj` project file format version. This is intended for internal use by CMake and should not be used by project code.
