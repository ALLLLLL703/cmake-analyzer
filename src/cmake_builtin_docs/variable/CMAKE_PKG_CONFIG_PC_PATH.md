# CMAKE_PKG_CONFIG_PC_PATH

Added in version 4.0.

[Semicolon-separated list](https://cmake.org/cmake/help/v4.4/manual/cmake-language.7.html#cmake-language-lists) of supplementary paths which the [`cmake_pkg_config()`](https://cmake.org/cmake/help/v4.4/command/cmake_pkg_config.html#command:cmake_pkg_config) command will search for package files by default. Also used to derive the `pc_path` package variable.
