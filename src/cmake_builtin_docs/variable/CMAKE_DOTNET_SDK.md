# CMAKE_DOTNET_SDK

Added in version 3.23.

Default value for [`DOTNET_SDK`](https://cmake.org/cmake/help/v4.4/prop_tgt/DOTNET_SDK.html#prop_tgt:DOTNET_SDK) property of targets.

This variable is used to initialize the [`DOTNET_SDK`](https://cmake.org/cmake/help/v4.4/prop_tgt/DOTNET_SDK.html#prop_tgt:DOTNET_SDK) property on all targets. See that target property for additional information.
