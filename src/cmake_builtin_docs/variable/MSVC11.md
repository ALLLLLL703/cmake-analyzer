# MSVC11

Discouraged. Use the [`MSVC_VERSION`](https://cmake.org/cmake/help/v4.4/variable/MSVC_VERSION.html#variable:MSVC_VERSION) variable instead.

`True` when using the Microsoft Visual Studio `v110` toolset (`cl` version 17) or another compiler that simulates it.
