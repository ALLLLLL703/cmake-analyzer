# CMAKE_PKG_CONFIG_DISABLE_UNINSTALLED

Added in version 4.0.

Enable / Disable the default "uninstalled" search behavior of the [`cmake_pkg_config()`](https://cmake.org/cmake/help/v4.4/command/cmake_pkg_config.html#command:cmake_pkg_config) command. When this variable is false, package files with an "-uninstalled" suffix have higher priority than exact package name matches.
