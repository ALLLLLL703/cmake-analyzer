# CMAKE_VS_DEVENV_COMMAND

The [Visual Studio Generators](https://cmake.org/cmake/help/v4.4/manual/cmake-generators.7.html#visual-studio-generators) set this variable to the `devenv.com` command installed with the corresponding Visual Studio version.

This variable is not defined by other generators even if `devenv.com` is installed on the computer.

See also the [`CMAKE_VS_MSBUILD_COMMAND`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_VS_MSBUILD_COMMAND.html#variable:CMAKE_VS_MSBUILD_COMMAND) and [`CMAKE_MAKE_PROGRAM`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_MAKE_PROGRAM.html#variable:CMAKE_MAKE_PROGRAM) variables.
