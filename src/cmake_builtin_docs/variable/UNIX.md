# UNIX

Set to `True` when the target system is UNIX or UNIX-like (e.g. [`APPLE`](https://cmake.org/cmake/help/v4.4/variable/APPLE.html#variable:APPLE) and [`CYGWIN`](https://cmake.org/cmake/help/v4.4/variable/CYGWIN.html#variable:CYGWIN)). The [`CMAKE_SYSTEM_NAME`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_SYSTEM_NAME.html#variable:CMAKE_SYSTEM_NAME) variable should be queried if a more specific understanding of the target system is required.
