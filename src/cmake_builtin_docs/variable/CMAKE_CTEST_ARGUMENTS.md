# CMAKE_CTEST_ARGUMENTS

Added in version 3.17.

Set this to a [semicolon-separated list](https://cmake.org/cmake/help/v4.4/manual/cmake-language.7.html#cmake-language-lists) of command-line arguments to pass to [`ctest(1)`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#manual:ctest(1)) when running tests through the `test` (or `RUN_TESTS`) target of the generated build system.
