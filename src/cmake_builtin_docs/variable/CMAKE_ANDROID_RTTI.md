# CMAKE_ANDROID_RTTI

Added in version 3.20.

When [Cross Compiling for Android with the NDK](https://cmake.org/cmake/help/v4.4/manual/cmake-toolchains.7.html#cross-compiling-for-android-with-the-ndk), this variable may be set to specify whether RTTI is enabled.
