# CMAKE_INSTALL_REMOVE_ENVIRONMENT_RPATH

Added in version 3.16.

Sets the default for whether toolchain-defined rpaths should be removed during installation.

`CMAKE_INSTALL_REMOVE_ENVIRONMENT_RPATH` is a boolean that provides the default value for the [`INSTALL_REMOVE_ENVIRONMENT_RPATH`](https://cmake.org/cmake/help/v4.4/prop_tgt/INSTALL_REMOVE_ENVIRONMENT_RPATH.html#prop_tgt:INSTALL_REMOVE_ENVIRONMENT_RPATH) property of all subsequently created targets.
