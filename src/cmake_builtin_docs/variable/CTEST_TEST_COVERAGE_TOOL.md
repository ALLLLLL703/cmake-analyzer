# CTEST_TEST_COVERAGE_TOOL

Added in version 4.4.

Specify the CTest [CoverageTool](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#ctest-coveragetool) setting in a [`ctest(1)`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#manual:ctest(1)) [Dashboard Client](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#dashboard-client) script, or on the **ctest** command line via the [`-D`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#cmdoption-ctest-dashboard-D) option.
