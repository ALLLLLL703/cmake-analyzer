# CMAKE_SYSTEM_LIBRARY_PATH

[Semicolon-separated list](https://cmake.org/cmake/help/v4.4/manual/cmake-language.7.html#cmake-language-lists) of directories specifying a search path for the [`find_library()`](https://cmake.org/cmake/help/v4.4/command/find_library.html#command:find_library) command. By default this contains the standard directories for the current system. It is *not* intended to be modified by the project; use [`CMAKE_LIBRARY_PATH`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_LIBRARY_PATH.html#variable:CMAKE_LIBRARY_PATH) for this. See also [`CMAKE_SYSTEM_PREFIX_PATH`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_SYSTEM_PREFIX_PATH.html#variable:CMAKE_SYSTEM_PREFIX_PATH).
