# CMAKE_Fortran_PREPROCESS

Added in version 3.18.

Default value for [`Fortran_PREPROCESS`](https://cmake.org/cmake/help/v4.4/prop_tgt/Fortran_PREPROCESS.html#prop_tgt:Fortran_PREPROCESS) of targets.

This variable is used to initialize the [`Fortran_PREPROCESS`](https://cmake.org/cmake/help/v4.4/prop_tgt/Fortran_PREPROCESS.html#prop_tgt:Fortran_PREPROCESS) property on all the targets. See that target property for additional information.
