# CMAKE_LIBRARY_ARCHITECTURE_REGEX

Regex matching possible target architecture library directory names.

This is used to detect [`CMAKE_<LANG>_LIBRARY_ARCHITECTURE`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_LANG_LIBRARY_ARCHITECTURE.html#variable:CMAKE_%3CLANG%3E_LIBRARY_ARCHITECTURE) from the implicit linker search path by matching the `<arch>` name.
