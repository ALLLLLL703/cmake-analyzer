# CMAKE_XCODE_SCHEME_DEBUG_DOCUMENT_VERSIONING

Added in version 3.16.

Whether to enable `Allow debugging when using document Versions Browser` in the Options section of the generated Xcode scheme.

This variable initializes the [`XCODE_SCHEME_DEBUG_DOCUMENT_VERSIONING`](https://cmake.org/cmake/help/v4.4/prop_tgt/XCODE_SCHEME_DEBUG_DOCUMENT_VERSIONING.html#prop_tgt:XCODE_SCHEME_DEBUG_DOCUMENT_VERSIONING) property on all targets.

Please refer to the [`XCODE_GENERATE_SCHEME`](https://cmake.org/cmake/help/v4.4/prop_tgt/XCODE_GENERATE_SCHEME.html#prop_tgt:XCODE_GENERATE_SCHEME) target property documentation to see all Xcode schema related properties.
