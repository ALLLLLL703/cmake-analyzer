# PROJECT_HOMEPAGE_URL

Added in version 3.12.

The homepage URL of the project.

This is the homepage URL given to the most recently called [`project()`](https://cmake.org/cmake/help/v4.4/command/project.html#command:project) command in the current directory scope or above. To obtain the homepage URL of the top level project, see the [`CMAKE_PROJECT_HOMEPAGE_URL`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_PROJECT_HOMEPAGE_URL.html#variable:CMAKE_PROJECT_HOMEPAGE_URL) variable.
