# CMAKE_RUNTIME_OUTPUT_DIRECTORY_\<CONFIG\>

Added in version 3.3.

Where to put all the [RUNTIME](https://cmake.org/cmake/help/v4.4/manual/cmake-buildsystem.7.html#runtime-output-artifacts) target files when built for a specific configuration.

This variable is used to initialize the [`RUNTIME_OUTPUT_DIRECTORY_<CONFIG>`](https://cmake.org/cmake/help/v4.4/prop_tgt/RUNTIME_OUTPUT_DIRECTORY_CONFIG.html#prop_tgt:RUNTIME_OUTPUT_DIRECTORY_%3CCONFIG%3E) property on all the targets. See that target property for additional information.
