# CMAKE_LINK_LIBRARIES_STRATEGY

Added in version 3.31.

Specify a strategy for ordering targets' direct link dependencies on linker command lines.

If set, this variable acts as the default value for the [`LINK_LIBRARIES_STRATEGY`](https://cmake.org/cmake/help/v4.4/prop_tgt/LINK_LIBRARIES_STRATEGY.html#prop_tgt:LINK_LIBRARIES_STRATEGY) target property when a target is created. Set that property directly to specify a strategy for a single target.
