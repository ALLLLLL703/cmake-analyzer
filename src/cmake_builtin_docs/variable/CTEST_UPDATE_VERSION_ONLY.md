# CTEST_UPDATE_VERSION_ONLY

Added in version 3.1.

Specify the CTest [UpdateVersionOnly](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#updateversiononly) setting in a [`ctest(1)`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#manual:ctest(1)) [Dashboard Client](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#dashboard-client) script, or on the **ctest** command line via the [`-D`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#cmdoption-ctest-dashboard-D) option.
