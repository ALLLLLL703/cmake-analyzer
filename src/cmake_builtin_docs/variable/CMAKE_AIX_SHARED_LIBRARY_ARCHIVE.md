# CMAKE_AIX_SHARED_LIBRARY_ARCHIVE

Added in version 3.31.

On AIX, enable or disable creation of shared library archives.

This variable initializes the [`AIX_SHARED_LIBRARY_ARCHIVE`](https://cmake.org/cmake/help/v4.4/prop_tgt/AIX_SHARED_LIBRARY_ARCHIVE.html#prop_tgt:AIX_SHARED_LIBRARY_ARCHIVE) target property on non-imported `SHARED` library targets as they are created by [`add_library()`](https://cmake.org/cmake/help/v4.4/command/add_library.html#command:add_library). See that target property for details.
