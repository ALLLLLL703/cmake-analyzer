# CTEST_TEST_LOAD

Added in version 3.4.

Specify the `TestLoad` setting in the [CTest Test Step](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#ctest-test-step) of a [`ctest(1)`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#manual:ctest(1)) [Dashboard Client](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#dashboard-client) script, or on the **ctest** command line via the [`-D`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#cmdoption-ctest-dashboard-D) option. This sets the default value for the `TEST_LOAD` option of the [`ctest_test()`](https://cmake.org/cmake/help/v4.4/command/ctest_test.html#command:ctest_test) command.
