# CMAKE_EXTRA_SHARED_LIBRARY_SUFFIXES

Additional suffixes for shared libraries.

Extensions for shared libraries other than that specified by [`CMAKE_SHARED_LIBRARY_SUFFIX`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_SHARED_LIBRARY_SUFFIX.html#variable:CMAKE_SHARED_LIBRARY_SUFFIX), if any. CMake uses this to recognize external shared library files during analysis of libraries linked by a target.
