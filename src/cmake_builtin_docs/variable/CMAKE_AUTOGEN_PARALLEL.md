# CMAKE_AUTOGEN_PARALLEL

Added in version 3.11.

Number of parallel `moc` or `uic` processes to start when using [`AUTOMOC`](https://cmake.org/cmake/help/v4.4/prop_tgt/AUTOMOC.html#prop_tgt:AUTOMOC) and [`AUTOUIC`](https://cmake.org/cmake/help/v4.4/prop_tgt/AUTOUIC.html#prop_tgt:AUTOUIC).

This variable is used to initialize the [`AUTOGEN_PARALLEL`](https://cmake.org/cmake/help/v4.4/prop_tgt/AUTOGEN_PARALLEL.html#prop_tgt:AUTOGEN_PARALLEL) property on all the targets. See that target property for additional information.

By default `CMAKE_AUTOGEN_PARALLEL` is unset.
