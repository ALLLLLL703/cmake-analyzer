# PROJECT_VERSION

Value given to the `VERSION` option of the most recent call to the [`project()`](https://cmake.org/cmake/help/v4.4/command/project.html#command:project) command, if any.

See also the component-wise version variables [`PROJECT_VERSION_MAJOR`](https://cmake.org/cmake/help/v4.4/variable/PROJECT_VERSION_MAJOR.html#variable:PROJECT_VERSION_MAJOR), [`PROJECT_VERSION_MINOR`](https://cmake.org/cmake/help/v4.4/variable/PROJECT_VERSION_MINOR.html#variable:PROJECT_VERSION_MINOR), [`PROJECT_VERSION_PATCH`](https://cmake.org/cmake/help/v4.4/variable/PROJECT_VERSION_PATCH.html#variable:PROJECT_VERSION_PATCH), and [`PROJECT_VERSION_TWEAK`](https://cmake.org/cmake/help/v4.4/variable/PROJECT_VERSION_TWEAK.html#variable:PROJECT_VERSION_TWEAK).
