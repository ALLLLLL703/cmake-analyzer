# CMAKE_\<LANG\>_COMPILER_LOADED

Defined to true if the language is enabled.

When language `<LANG>` is enabled by [`project()`](https://cmake.org/cmake/help/v4.4/command/project.html#command:project) or [`enable_language()`](https://cmake.org/cmake/help/v4.4/command/enable_language.html#command:enable_language) this variable is defined to `1`.
