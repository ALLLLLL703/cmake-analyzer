# CMAKE_EDIT_COMMAND

Full path to [`cmake-gui(1)`](https://cmake.org/cmake/help/v4.4/manual/cmake-gui.1.html#manual:cmake-gui(1)) or [`ccmake(1)`](https://cmake.org/cmake/help/v4.4/manual/ccmake.1.html#manual:ccmake(1)). Defined only for [Makefile Generators](https://cmake.org/cmake/help/v4.4/manual/cmake-generators.7.html#makefile-generators) and [Ninja Generators](https://cmake.org/cmake/help/v4.4/manual/cmake-generators.7.html#ninja-generators) when not using any [Extra Generators](https://cmake.org/cmake/help/v4.4/manual/cmake-generators.7.html#extra-generators).

This is the full path to the CMake executable that can graphically edit the cache. For example, [`cmake-gui(1)`](https://cmake.org/cmake/help/v4.4/manual/cmake-gui.1.html#manual:cmake-gui(1)) or [`ccmake(1)`](https://cmake.org/cmake/help/v4.4/manual/ccmake.1.html#manual:ccmake(1)).
