# CMAKE_PKG_CONFIG_SYSROOT_DIR

Added in version 4.0.

Path prepended to `-I` include directories and `-L` library directories extracted by the [`cmake_pkg_config()`](https://cmake.org/cmake/help/v4.4/command/cmake_pkg_config.html#command:cmake_pkg_config) command by default. Also used to derive the `pc_sysrootdir` package variable.
