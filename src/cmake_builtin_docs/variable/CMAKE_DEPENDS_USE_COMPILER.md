# CMAKE_DEPENDS_USE_COMPILER

Added in version 3.20.

For the [Makefile Generators](https://cmake.org/cmake/help/v4.4/manual/cmake-generators.7.html#makefile-generators), source dependencies are now, for a selection of compilers, generated by the compiler itself. By defining this variable with value `FALSE`, you can restore the legacy behavior (i.e. using CMake for dependencies discovery).
