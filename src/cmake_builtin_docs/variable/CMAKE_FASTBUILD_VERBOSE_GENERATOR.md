# CMAKE_FASTBUILD_VERBOSE_GENERATOR

Added in version 4.2.

Enables verbose logging during FASTBuild file generation.

Initialized by the [`CMAKE_FASTBUILD_VERBOSE_GENERATOR`](https://cmake.org/cmake/help/v4.4/envvar/CMAKE_FASTBUILD_VERBOSE_GENERATOR.html#envvar:CMAKE_FASTBUILD_VERBOSE_GENERATOR) environment variable.

Defaults to `OFF`.
