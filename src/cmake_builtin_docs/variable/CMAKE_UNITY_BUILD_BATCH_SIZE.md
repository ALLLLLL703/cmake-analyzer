# CMAKE_UNITY_BUILD_BATCH_SIZE

Added in version 3.16.

This variable is used to initialize the [`UNITY_BUILD_BATCH_SIZE`](https://cmake.org/cmake/help/v4.4/prop_tgt/UNITY_BUILD_BATCH_SIZE.html#prop_tgt:UNITY_BUILD_BATCH_SIZE) property of targets when they are created. It specifies the default upper limit on the number of source files that may be combined in any one unity source file when unity builds are enabled for a target.
