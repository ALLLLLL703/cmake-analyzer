# CMAKE_XCODE_GENERATE_SCHEME

Added in version 3.9.

If enabled, the [`Xcode`](https://cmake.org/cmake/help/v4.4/generator/Xcode.html#generator:Xcode) generator will generate schema files. These are useful to invoke analyze, archive, build-for-testing and test actions from the command line.

This variable initializes the [`XCODE_GENERATE_SCHEME`](https://cmake.org/cmake/help/v4.4/prop_tgt/XCODE_GENERATE_SCHEME.html#prop_tgt:XCODE_GENERATE_SCHEME) target property on all targets.
