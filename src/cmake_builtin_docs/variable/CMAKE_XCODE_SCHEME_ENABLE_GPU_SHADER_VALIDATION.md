# CMAKE_XCODE_SCHEME_ENABLE_GPU_SHADER_VALIDATION

Added in version 3.25.

Populate `Metal: Shader Validation` in the Options section of the generated Xcode scheme.

This variable initializes the [`XCODE_SCHEME_ENABLE_GPU_SHADER_VALIDATION`](https://cmake.org/cmake/help/v4.4/prop_tgt/XCODE_SCHEME_ENABLE_GPU_SHADER_VALIDATION.html#prop_tgt:XCODE_SCHEME_ENABLE_GPU_SHADER_VALIDATION) property on all targets.

Please refer to the [`XCODE_GENERATE_SCHEME`](https://cmake.org/cmake/help/v4.4/prop_tgt/XCODE_GENERATE_SCHEME.html#prop_tgt:XCODE_GENERATE_SCHEME) target property documentation to see all Xcode schema related properties.
