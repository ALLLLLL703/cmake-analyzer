# PROJECT_DESCRIPTION

Added in version 3.9.

Short project description given to the project command.

This is the description given to the most recently called [`project()`](https://cmake.org/cmake/help/v4.4/command/project.html#command:project) command in the current directory scope or above. To obtain the description of the top level project, see the [`CMAKE_PROJECT_DESCRIPTION`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_PROJECT_DESCRIPTION.html#variable:CMAKE_PROJECT_DESCRIPTION) variable.
