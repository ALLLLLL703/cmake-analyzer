# CMAKE_CUDA_COMPILE_FEATURES

Added in version 3.17.

List of features known to the CUDA compiler

These features are known to be available for use with the CUDA compiler. This list is a subset of the features listed in the [`CMAKE_CUDA_KNOWN_FEATURES`](https://cmake.org/cmake/help/v4.4/prop_gbl/CMAKE_CUDA_KNOWN_FEATURES.html#prop_gbl:CMAKE_CUDA_KNOWN_FEATURES) global property.

See the [`cmake-compile-features(7)`](https://cmake.org/cmake/help/v4.4/manual/cmake-compile-features.7.html#manual:cmake-compile-features(7)) manual for information on compile features and a list of supported compilers.
