# CTEST_CURL_OPTIONS

Deprecated since version 3.30: Use the [`CTEST_TLS_VERIFY`](https://cmake.org/cmake/help/v4.4/variable/CTEST_TLS_VERIFY.html#variable:CTEST_TLS_VERIFY) variable instead.

Added in version 3.1.

Specify the CTest `CurlOptions` setting in a [`ctest(1)`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#manual:ctest(1)) [Dashboard Client](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#dashboard-client) script, or on the **ctest** command line via the [`-D`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#cmdoption-ctest-dashboard-D) option.
