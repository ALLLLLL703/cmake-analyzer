# CMAKE_AUTOUIC_EXECUTABLE

Added in version 3.27.

This variable is used to initialize the [`AUTOUIC_EXECUTABLE`](https://cmake.org/cmake/help/v4.4/prop_tgt/AUTOUIC_EXECUTABLE.html#prop_tgt:AUTOUIC_EXECUTABLE) property on all the targets. See that target property for additional information.

By default it is empty.
