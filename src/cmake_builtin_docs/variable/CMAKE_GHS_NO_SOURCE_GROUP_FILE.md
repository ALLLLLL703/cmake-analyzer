# CMAKE_GHS_NO_SOURCE_GROUP_FILE

Added in version 3.14.

`ON` / `OFF` boolean to control if the project file for a target should be one single file or multiple files. Refer to [`GHS_NO_SOURCE_GROUP_FILE`](https://cmake.org/cmake/help/v4.4/prop_tgt/GHS_NO_SOURCE_GROUP_FILE.html#prop_tgt:GHS_NO_SOURCE_GROUP_FILE) for further details.
