# CMAKE_\<LANG\>_ANDROID_TOOLCHAIN_MACHINE

Added in version 3.7.1.

When [Cross Compiling for Android](https://cmake.org/cmake/help/v4.4/manual/cmake-toolchains.7.html#cross-compiling-for-android) this variable contains the toolchain binutils machine name (e.g. `gcc -dumpmachine`). The binutils typically have a `<machine>-` prefix on their name.

See also [`CMAKE_<LANG>_ANDROID_TOOLCHAIN_PREFIX`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_LANG_ANDROID_TOOLCHAIN_PREFIX.html#variable:CMAKE_%3CLANG%3E_ANDROID_TOOLCHAIN_PREFIX) and [`CMAKE_<LANG>_ANDROID_TOOLCHAIN_SUFFIX`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_LANG_ANDROID_TOOLCHAIN_SUFFIX.html#variable:CMAKE_%3CLANG%3E_ANDROID_TOOLCHAIN_SUFFIX).
