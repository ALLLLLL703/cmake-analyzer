# CMAKE_SUBLIME_TEXT_2_EXCLUDE_BUILD_TREE

Added in version 3.8.

If this variable evaluates to `ON` at the end of the top-level `CMakeLists.txt` file, the [`Sublime Text 2`](https://cmake.org/cmake/help/v4.4/generator/Sublime%20Text%202.html#generator:Sublime%20Text%202) extra generator excludes the build tree from the `.sublime-project` if it is inside the source tree.
