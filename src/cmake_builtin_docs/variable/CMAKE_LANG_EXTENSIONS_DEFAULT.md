# CMAKE_\<LANG\>_EXTENSIONS_DEFAULT

Added in version 3.22.

Compiler's default extensions mode. Used as the default for the [`<LANG>_EXTENSIONS`](https://cmake.org/cmake/help/v4.4/prop_tgt/LANG_EXTENSIONS.html#prop_tgt:%3CLANG%3E_EXTENSIONS) target property when [`CMAKE_<LANG>_EXTENSIONS`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_LANG_EXTENSIONS.html#variable:CMAKE_%3CLANG%3E_EXTENSIONS) is not set (see [`CMP0128`](https://cmake.org/cmake/help/v4.4/policy/CMP0128.html#policy:CMP0128)).

This variable is read-only. Modifying it is undefined behavior.
