# CTEST_TEST_PRESET

Added in version 4.4.

Specify the `PRESET` option for the [`ctest_test()`](https://cmake.org/cmake/help/v4.4/command/ctest_test.html#command:ctest_test) and [`ctest_memcheck()`](https://cmake.org/cmake/help/v4.4/command/ctest_memcheck.html#command:ctest_memcheck) commands in a [`ctest(1)`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#manual:ctest(1)) [Dashboard Client](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#dashboard-client) script, or on the **ctest** command line via the [`-D`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#cmdoption-ctest-dashboard-D) option.

See also [`CTEST_PRESET`](https://cmake.org/cmake/help/v4.4/variable/CTEST_PRESET.html#variable:CTEST_PRESET) and [`CTEST_PRESETS_FILE`](https://cmake.org/cmake/help/v4.4/variable/CTEST_PRESETS_FILE.html#variable:CTEST_PRESETS_FILE).
