# CMAKE_JOB_POOLS

Added in version 3.11.

If the [`JOB_POOLS`](https://cmake.org/cmake/help/v4.4/prop_gbl/JOB_POOLS.html#prop_gbl:JOB_POOLS) global property is not set, the value of this variable is used in its place. See [`JOB_POOLS`](https://cmake.org/cmake/help/v4.4/prop_gbl/JOB_POOLS.html#prop_gbl:JOB_POOLS) for additional information.
