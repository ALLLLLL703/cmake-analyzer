# CMAKE_WIN32_EXECUTABLE

Default value for [`WIN32_EXECUTABLE`](https://cmake.org/cmake/help/v4.4/prop_tgt/WIN32_EXECUTABLE.html#prop_tgt:WIN32_EXECUTABLE) of targets.

This variable is used to initialize the [`WIN32_EXECUTABLE`](https://cmake.org/cmake/help/v4.4/prop_tgt/WIN32_EXECUTABLE.html#prop_tgt:WIN32_EXECUTABLE) property on all the targets. See that target property for additional information.
