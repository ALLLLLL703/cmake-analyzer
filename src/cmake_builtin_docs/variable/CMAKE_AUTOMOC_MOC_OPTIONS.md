# CMAKE_AUTOMOC_MOC_OPTIONS

Additional options for `moc` when using [`CMAKE_AUTOMOC`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_AUTOMOC.html#variable:CMAKE_AUTOMOC).

This variable is used to initialize the [`AUTOMOC_MOC_OPTIONS`](https://cmake.org/cmake/help/v4.4/prop_tgt/AUTOMOC_MOC_OPTIONS.html#prop_tgt:AUTOMOC_MOC_OPTIONS) property on all the targets. See that target property for additional information.
