# CMAKE_\<LANG\>_ANDROID_TOOLCHAIN_SUFFIX

Added in version 3.7.

When [Cross Compiling for Android](https://cmake.org/cmake/help/v4.4/manual/cmake-toolchains.7.html#cross-compiling-for-android) this variable contains the host platform suffix of the toolchain GNU compiler and its binutils.

See also [`CMAKE_<LANG>_ANDROID_TOOLCHAIN_PREFIX`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_LANG_ANDROID_TOOLCHAIN_PREFIX.html#variable:CMAKE_%3CLANG%3E_ANDROID_TOOLCHAIN_PREFIX) and [`CMAKE_<LANG>_ANDROID_TOOLCHAIN_MACHINE`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_LANG_ANDROID_TOOLCHAIN_MACHINE.html#variable:CMAKE_%3CLANG%3E_ANDROID_TOOLCHAIN_MACHINE).
