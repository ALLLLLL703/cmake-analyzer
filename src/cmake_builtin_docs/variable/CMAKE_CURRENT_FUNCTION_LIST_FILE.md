# CMAKE_CURRENT_FUNCTION_LIST_FILE

Added in version 3.17.

When executing code inside a [`function()`](https://cmake.org/cmake/help/v4.4/command/function.html#command:function), this variable contains the full path to the listfile that defined the current function.

See also [`CMAKE_CURRENT_FUNCTION`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_CURRENT_FUNCTION.html#variable:CMAKE_CURRENT_FUNCTION), [`CMAKE_CURRENT_FUNCTION_LIST_DIR`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_CURRENT_FUNCTION_LIST_DIR.html#variable:CMAKE_CURRENT_FUNCTION_LIST_DIR), [`CMAKE_CURRENT_FUNCTION_LIST_LINE`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_CURRENT_FUNCTION_LIST_LINE.html#variable:CMAKE_CURRENT_FUNCTION_LIST_LINE) and [`CMAKE_CURRENT_LIST_FILE`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_CURRENT_LIST_FILE.html#variable:CMAKE_CURRENT_LIST_FILE).
