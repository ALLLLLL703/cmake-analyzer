# CMAKE_ISPC_HEADER_DIRECTORY

Added in version 3.19.

This variable is used to initialize the [`ISPC_HEADER_DIRECTORY`](https://cmake.org/cmake/help/v4.4/prop_tgt/ISPC_HEADER_DIRECTORY.html#prop_tgt:ISPC_HEADER_DIRECTORY) property on all the targets. See the target property for additional information.
