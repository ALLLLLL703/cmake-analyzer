# GHSMULTI

Added in version 3.3.

`1` when using [`Green Hills MULTI`](https://cmake.org/cmake/help/v4.4/generator/Green%20Hills%20MULTI.html#generator:Green%20Hills%20MULTI) generator.

Also, Set to `1` when the target system is a Green Hills platform (i.e. When [`CMAKE_SYSTEM_NAME`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_SYSTEM_NAME.html#variable:CMAKE_SYSTEM_NAME) is `GHS-MULTI`).
