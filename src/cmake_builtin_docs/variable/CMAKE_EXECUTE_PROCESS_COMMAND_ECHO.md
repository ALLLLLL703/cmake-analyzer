# CMAKE_EXECUTE_PROCESS_COMMAND_ECHO

Added in version 3.15.

If this variable is set to `STDERR`, `STDOUT` or `NONE` then commands in [`execute_process()`](https://cmake.org/cmake/help/v4.4/command/execute_process.html#command:execute_process) calls will be printed to either stderr or stdout or not at all.
