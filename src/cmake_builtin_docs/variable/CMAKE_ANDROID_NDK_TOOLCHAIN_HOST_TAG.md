# CMAKE_ANDROID_NDK_TOOLCHAIN_HOST_TAG

Added in version 3.7.1.

When [Cross Compiling for Android with the NDK](https://cmake.org/cmake/help/v4.4/manual/cmake-toolchains.7.html#cross-compiling-for-android-with-the-ndk), this variable provides the NDK's "host tag" used to construct the path to prebuilt toolchains that run on the host.
