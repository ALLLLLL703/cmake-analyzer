# CMAKE_GNUtoMS

Convert GNU import libraries (`.dll.a`) to MS format (`.lib`).

This variable is used to initialize the [`GNUtoMS`](https://cmake.org/cmake/help/v4.4/prop_tgt/GNUtoMS.html#prop_tgt:GNUtoMS) property on targets when they are created. See that target property for additional information.
