# CMAKE_\<LANG\>_CPPCHECK

Added in version 3.10.

Default value for [`<LANG>_CPPCHECK`](https://cmake.org/cmake/help/v4.4/prop_tgt/LANG_CPPCHECK.html#prop_tgt:%3CLANG%3E_CPPCHECK) target property. This variable is used to initialize the property on each target as it is created. This is done only when `<LANG>` is `C` or `CXX`.
