# CMAKE_RULE_MESSAGES

Added in version 3.13.

Specify whether to report a message for each make rule.

If set in the cache it is used to initialize the value of the [`RULE_MESSAGES`](https://cmake.org/cmake/help/v4.4/prop_gbl/RULE_MESSAGES.html#prop_gbl:RULE_MESSAGES) property. Users may disable the option in their local build tree to disable granular messages and report only as each target completes in Makefile builds.
