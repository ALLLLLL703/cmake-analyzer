# CMAKE_Fortran_MODDIR_DEFAULT

Fortran default module output directory.

Most Fortran compilers write `.mod` files to the current working directory. For those that do not, this is set to `.` and used when the [`Fortran_MODULE_DIRECTORY`](https://cmake.org/cmake/help/v4.4/prop_tgt/Fortran_MODULE_DIRECTORY.html#prop_tgt:Fortran_MODULE_DIRECTORY) target property is not set.
