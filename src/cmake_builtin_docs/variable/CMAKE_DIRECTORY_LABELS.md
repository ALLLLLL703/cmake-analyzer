# CMAKE_DIRECTORY_LABELS

Added in version 3.10.

Specify labels for the current directory.

This is used to initialize the [`LABELS`](https://cmake.org/cmake/help/v4.4/prop_dir/LABELS.html#prop_dir:LABELS) directory property.
