# CMAKE_BUILD_WITH_INSTALL_NAME_DIR

Added in version 3.9.

Whether to use [`INSTALL_NAME_DIR`](https://cmake.org/cmake/help/v4.4/prop_tgt/INSTALL_NAME_DIR.html#prop_tgt:INSTALL_NAME_DIR) on targets in the build tree.

This variable is used to initialize the [`BUILD_WITH_INSTALL_NAME_DIR`](https://cmake.org/cmake/help/v4.4/prop_tgt/BUILD_WITH_INSTALL_NAME_DIR.html#prop_tgt:BUILD_WITH_INSTALL_NAME_DIR) property on all targets.
