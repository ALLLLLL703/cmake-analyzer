# CMAKE_SKIP_LINTING

Added in version 4.2.

Default value for the [`SKIP_LINTING`](https://cmake.org/cmake/help/v4.4/prop_tgt/SKIP_LINTING.html#prop_tgt:SKIP_LINTING) target property.

This is used to initialize the [`SKIP_LINTING`](https://cmake.org/cmake/help/v4.4/prop_tgt/SKIP_LINTING.html#prop_tgt:SKIP_LINTING) target property for all targets created *afterward*.
