# CMAKE_COMPILE_PDB_OUTPUT_DIRECTORY

Added in version 3.1.

Output directory for MS debug symbol `.pdb` files generated by the compiler while building source files.

This variable is used to initialize the [`COMPILE_PDB_OUTPUT_DIRECTORY`](https://cmake.org/cmake/help/v4.4/prop_tgt/COMPILE_PDB_OUTPUT_DIRECTORY.html#prop_tgt:COMPILE_PDB_OUTPUT_DIRECTORY) property on all the targets.
