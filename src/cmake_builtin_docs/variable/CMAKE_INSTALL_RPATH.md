# CMAKE_INSTALL_RPATH

The rpath to use for installed targets.

A semicolon-separated list specifying the rpath to use in installed targets (for platforms that support it). This is used to initialize the target property [`INSTALL_RPATH`](https://cmake.org/cmake/help/v4.4/prop_tgt/INSTALL_RPATH.html#prop_tgt:INSTALL_RPATH) for all targets.
