# CMAKE_\<LANG\>_INCLUDE_WHAT_YOU_USE

Added in version 3.3.

Default value for [`<LANG>_INCLUDE_WHAT_YOU_USE`](https://cmake.org/cmake/help/v4.4/prop_tgt/LANG_INCLUDE_WHAT_YOU_USE.html#prop_tgt:%3CLANG%3E_INCLUDE_WHAT_YOU_USE) target property.
