# CMAKE_CUDA_TOOLKIT_INCLUDE_DIRECTORIES

Added in version 3.8.

When the `CUDA` language has been enabled, this provides a [semicolon-separated list](https://cmake.org/cmake/help/v4.4/manual/cmake-language.7.html#cmake-language-lists) of include directories provided by the CUDA Toolkit. The value may be useful for C++ source files to include CUDA headers.
