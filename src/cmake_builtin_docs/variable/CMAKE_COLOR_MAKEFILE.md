# CMAKE_COLOR_MAKEFILE

Enables color output when using the [Makefile Generators](https://cmake.org/cmake/help/v4.4/manual/cmake-generators.7.html#makefile-generators).

When enabled, the generated Makefiles will produce colored output. Default is `ON`.
