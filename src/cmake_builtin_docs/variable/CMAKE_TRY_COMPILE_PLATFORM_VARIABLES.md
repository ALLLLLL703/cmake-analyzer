# CMAKE_TRY_COMPILE_PLATFORM_VARIABLES

Added in version 3.6.

List of variables that the [`try_compile()`](https://cmake.org/cmake/help/v4.4/command/try_compile.html#command:try_compile) command source file signature must propagate into the test project in order to target the same platform as the host project.

This variable should not be set by project code. It is meant to be set by CMake's platform information modules for the current toolchain, or by a toolchain file when used with [`CMAKE_TOOLCHAIN_FILE`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_TOOLCHAIN_FILE.html#variable:CMAKE_TOOLCHAIN_FILE).

Variables meaningful to CMake, such as [`CMAKE_<LANG>_FLAGS`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_LANG_FLAGS.html#variable:CMAKE_%3CLANG%3E_FLAGS), are propagated automatically. The `CMAKE_TRY_COMPILE_PLATFORM_VARIABLES` variable may be set to pass custom variables meaningful to a toolchain file. For example, a toolchain file may contain:

~~~
set(CMAKE_SYSTEM_NAME ...)
set(CMAKE_TRY_COMPILE_PLATFORM_VARIABLES MY_CUSTOM_VARIABLE)
# ... use MY_CUSTOM_VARIABLE ...
~~~

If a user passes `-DMY_CUSTOM_VARIABLE=SomeValue` to CMake then this setting will be made visible to the toolchain file both for the main project and for test projects generated by the [`try_compile()`](https://cmake.org/cmake/help/v4.4/command/try_compile.html#command:try_compile) command source file signature.

Changed in version 3.24: Listed variables are propagated to the [`try_compile()`](https://cmake.org/cmake/help/v4.4/command/try_compile.html#command:try_compile) [whole-project](https://cmake.org/cmake/help/v4.4/command/try_compile.html#try-compiling-whole-projects) signature too. See [`CMP0137`](https://cmake.org/cmake/help/v4.4/policy/CMP0137.html#policy:CMP0137).

Added in version 3.24: The [`CMAKE_TRY_COMPILE_NO_PLATFORM_VARIABLES`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_TRY_COMPILE_NO_PLATFORM_VARIABLES.html#variable:CMAKE_TRY_COMPILE_NO_PLATFORM_VARIABLES) variable may be set to disable passing platform variables into the test project.
