# CMAKE_AUTORCC

Whether to handle `rcc` automatically for Qt targets.

This variable is used to initialize the [`AUTORCC`](https://cmake.org/cmake/help/v4.4/prop_tgt/AUTORCC.html#prop_tgt:AUTORCC) property on all the targets. See that target property for additional information.
