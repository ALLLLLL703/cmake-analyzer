# CMAKE_XCODE_LINK_BUILD_PHASE_MODE

Added in version 3.19.

This variable is used to initialize the [`XCODE_LINK_BUILD_PHASE_MODE`](https://cmake.org/cmake/help/v4.4/prop_tgt/XCODE_LINK_BUILD_PHASE_MODE.html#prop_tgt:XCODE_LINK_BUILD_PHASE_MODE) property on targets. It affects the methods that the [`Xcode`](https://cmake.org/cmake/help/v4.4/generator/Xcode.html#generator:Xcode) generator uses to link different kinds of libraries. Its default value is `NONE`.
