# CMAKE_\<LANG\>_ICSTAT

Added in version 4.1.

Default value for [`<LANG>_ICSTAT`](https://cmake.org/cmake/help/v4.4/prop_tgt/LANG_ICSTAT.html#prop_tgt:%3CLANG%3E_ICSTAT) target property. This variable is used to initialize the property on each target as it is created. This is done only when `<LANG>` is `C` or `CXX`.
