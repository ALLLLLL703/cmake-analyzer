# CMAKE_ANDROID_STANDALONE_TOOLCHAIN

Added in version 3.7.

When [Cross Compiling for Android with a Standalone Toolchain](https://cmake.org/cmake/help/v4.4/manual/cmake-toolchains.7.html#cross-compiling-for-android-with-a-standalone-toolchain), this variable holds the absolute path to the root directory of the toolchain. The specified directory must contain a `sysroot` subdirectory.
