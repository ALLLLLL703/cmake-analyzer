# CMAKE_MACOSX_RPATH

Whether to use rpaths on macOS and iOS.

This variable is used to initialize the [`MACOSX_RPATH`](https://cmake.org/cmake/help/v4.4/prop_tgt/MACOSX_RPATH.html#prop_tgt:MACOSX_RPATH) property on all targets.
