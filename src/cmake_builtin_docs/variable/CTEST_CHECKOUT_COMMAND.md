# CTEST_CHECKOUT_COMMAND

Added in version 3.1.

Tell the [`ctest_start()`](https://cmake.org/cmake/help/v4.4/command/ctest_start.html#command:ctest_start) command how to checkout or initialize the source directory in a [`ctest(1)`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#manual:ctest(1)) [Dashboard Client](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#dashboard-client) script, or on the **ctest** command line via the [`-D`](https://cmake.org/cmake/help/v4.4/manual/ctest.1.html#cmdoption-ctest-dashboard-D) option.
