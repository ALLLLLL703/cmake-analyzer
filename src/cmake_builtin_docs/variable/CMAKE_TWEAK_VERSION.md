# CMAKE_TWEAK_VERSION

Defined to `0` for compatibility with code written for older CMake versions that may have defined higher values.

Note

In CMake versions 2.8.2 through 2.8.12, this variable holds the fourth version number component of the [`CMAKE_VERSION`](https://cmake.org/cmake/help/v4.4/variable/CMAKE_VERSION.html#variable:CMAKE_VERSION) variable.
