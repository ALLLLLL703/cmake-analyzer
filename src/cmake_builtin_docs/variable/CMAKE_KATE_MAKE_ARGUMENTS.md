# CMAKE_KATE_MAKE_ARGUMENTS

Added in version 3.0.

This cache variable is used by the Kate project generator. See [`cmake-generators(7)`](https://cmake.org/cmake/help/v4.4/manual/cmake-generators.7.html#manual:cmake-generators(7)).

This variable holds arguments which are used when Kate invokes the make tool. By default it is initialized to hold flags to enable parallel builds (using -j typically).
