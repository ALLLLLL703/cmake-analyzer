# CMAKE_UNITY_BUILD_UNIQUE_ID

Added in version 3.20.

This variable is used to initialize the [`UNITY_BUILD_UNIQUE_ID`](https://cmake.org/cmake/help/v4.4/prop_tgt/UNITY_BUILD_UNIQUE_ID.html#prop_tgt:UNITY_BUILD_UNIQUE_ID) property of targets when they are created. It specifies the name of the unique identifier generated per file in a unity build.
