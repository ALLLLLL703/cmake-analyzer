# subdir_depends

Disallowed since version 3.0. See CMake Policy [`CMP0029`](https://cmake.org/cmake/help/v4.4/policy/CMP0029.html#policy:CMP0029).

Does nothing.

~~~
subdir_depends(subdir dep1 dep2 ...)
~~~

Does not do anything. This command used to help projects order parallel builds correctly. This functionality is now automatic.
