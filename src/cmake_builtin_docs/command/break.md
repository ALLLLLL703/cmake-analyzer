# break

Break from an enclosing foreach or while loop.

~~~
break()
~~~

Breaks from an enclosing [`foreach()`](https://cmake.org/cmake/help/v4.4/command/foreach.html#command:foreach) or [`while()`](https://cmake.org/cmake/help/v4.4/command/while.html#command:while) loop.

See also the [`continue()`](https://cmake.org/cmake/help/v4.4/command/continue.html#command:continue) command.
