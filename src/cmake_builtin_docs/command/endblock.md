# endblock

Added in version 3.25.

Ends a list of commands in a [`block()`](https://cmake.org/cmake/help/v4.4/command/block.html#command:block) and removes the scopes created by the [`block()`](https://cmake.org/cmake/help/v4.4/command/block.html#command:block) command.

endblock()
